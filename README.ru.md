# Экосистема проектов Nargan

[Read in English (README.md)](README.md)

Единая отказоустойчивая веб-экосистема независимых приложений на FastAPI, Python и MongoDB. Монорепозиторий использует явный реестр проектов, профили хостингов, квоты ресурсов и отключаемую процессную изоляцию.

---

## Обзор архитектуры

Экосистемой управляет manifest `orchestrator.toml`:

1. **Явный реестр:** собираются, деплоятся и запускаются только объявленные проекты. Локальный `.project-ignore` служит fail-closed выключателем.
2. **Процессная изоляция:** профиль Hugging Face лениво запускает отдельный uvicorn worker для каждого проекта. Hub только проксирует HTTP/WebSocket, поэтому падение worker не останавливает соседей.
3. **Политики ресурсов:** ограничиваются трафик, конкурентность, таймауты, RAM, CPU, subprocess, соединения, временный диск и рестарты. Повторные сбои открывают circuit breaker.
4. **Совместимый монолитный режим:** `CUTAWAY_ISOLATION=embedded` сохраняет запуск в одном процессе для локальной разработки и ограниченных инфраструктур.
5. **Статус:** `/healthz` показывает состояние hub, а `/api/status` — состояние и ресурсы проектов.

Подробности приведены в [руководстве оркестратора](docs/orchestrator.md).

Часть каталогов есть только в GitHub-монорепозитории для локальной работы и CI. На этом Space они не собираются, не запускаются и не публикуются.

## Каталог экосистемы

### 🚀 Главный хаб
* **Лендинг (`index.html`, `main.py`):** Каталог проектов. Язык берётся из браузера, на странице виден счётчик посетителей, проект, который текущий профиль не запускает, в список не попадает, упавший проект тускнеет, фон — случайное видео. `GET /api` отдаёт ту же страницу JSON-ом: заголовок, приветствие на английском и русском, ссылки на GitHub и Telegram, число посетителей и карточки проектов.

### 📁 Реестр приложений

#### 1. [Formular](./formular/) (Кузница документов и медиа)
* **Описание:** Универсальный конвертер файлов «все-во-все», использующий программный алгоритм поиска кратчайшего пути Дейкстры.
* **Интеграции:** LibreOffice, Pandoc, PyMuPDF, FFmpeg, Pandas, Pillow, CairoSVG и 7-Zip. Локально HTML в PDF может идти через Chromium; на публичном Space — через LibreOffice.
* **Возможности:** Связывает разрозненные категории медиафайлов (например, Markdown ➔ HTML ➔ PDF или Excel ➔ CSV ➔ JSON ➔ XML), динамически собирая цепочку выполнения для любого поддерживаемого перехода.

#### 2. [Yellow Mirror](./yellow_mirror/) (Удаленный headless-браузер)
* **Описание:** Трансляция браузера через WebSockets только для доверенных доменов из allowlist. Проект остаётся в этом GitHub-монорепозитории и не публикуется на Hugging Face Space.
* **Возможности:** Изолированные сессии Chromium, кадры CDP screencast по WebSocket, перенаправление мыши и клавиатуры.

#### 3. [Toadcode](./toadcode/) (Среда совместной разработки)
* **Описание:** Интерактивное рабочее пространство с виртуальной файловой системой (VFS) для временных проектов.
* **Возможности:** Поддержка древовидной структуры папок, множественной загрузки файлов, распаковки архивов `.ZIP` и импорта репозиториев с GitHub через прокси. Включает инструмент выделения области (lasso), отображение номеров строк, базовое автодополнение и ограничение размера проекта в реальном времени (10 МБ).

#### 4. [Markbin](./markbin/) (Markdown-редактор и хостинг документов)
* **Описание:** Платформа для создания, просмотра и публикации Markdown-документов на базе движка Vditor.
* **Возможности:** Интерактивное визуальное редактирование, автогенерация оглавления, скачивание файлов на клиентской стороне и ссылки с автоудалением. Использует встроенные TTL-индексы MongoDB для автоматического удаления документов по истечении заданного времени жизни. `POST /markbin/api/docs` сохраняет документ, `GET /markbin/api/docs/{id}` читает его. Страница по-прежнему сохраняет через `POST /markbin/api/save`.

#### 5. [Kanban](./kanban/) (Минималистичный органайзер задач)
* **Описание:** Легковесный менеджер задач с рекурсивными вложенными списками и поддержкой drag-and-drop.
* **Возможности:** Бесконечная вложенность задач, экспорт и импорт конфигурации в формате JSON через native file picker, поддержка сенсорных экранов (drag-drop-touch), горячие клавиши и цветовое кодирование проектов.

#### 6. [D&D Tools](./dnd/) (Инструменты Мастера Подземелий)
* **Описание:** Утилиты под правила дикого облика 2014 года. `GET /dnd/api/beasts` отвечает на тот же поиск, что и страница.
* **Возможности:**
  * **Бестиарий и помощник по Wild Shape:** Поиск, фильтры, исключение через `-` и сортировка по характеристикам, в том числе по короткому слову вроде начала слова «скорость». На карточке указан источник. Ступени облика считаются из показателя опасности и передвижения.
  * **Просмотрщик бланков Foundry VTT:** Читает экспорт актёра Foundry 0.8–14 в браузере. Формулы бросков становятся кнопками. Разметка описания показывается текстом.

#### 7. [Evenfest](./evenfest/) (Сайт сообщества косплееров)
* **Описание:** Шаблонный сайт с управлением структурой через MongoDB и шаблоны Jinja2 для новостей, фотографов, билетов и правил. `GET /evenfest/api/pages` перечисляет страницы, `GET /evenfest/api/pages/{id}` возвращает текст, который показывает страница.

#### 8. [Snake](./snake/) (Органическая аркада)
* **Описание:** Аркадная игра «Змейка» на Canvas с физикой векторных частиц, динамическим масштабированием сложности и API для подгрузки случайных видеофонов.

#### 9. [Soon](./soon/) (Общая доска)
* **Описание:** Совместная доска без регистрации. Все в одной комнате рисуют на одном холсте; карточки на главной нет, адрес — `/soon`.
* **Возможности:** Живые штрихи и именные курсоры по WebSocket, вставка картинок (Ctrl+V и drag-and-drop) в Cloudinary с дедупом по хэшу, сворачиваемая панель, переход к человеку и метки по краям экрана. Одна общая комната на `/soon`.

#### 10. [ASCII City](./ascii_city/) (Многопользовательский ASCII-город)

* **Описание:** Киберпанк-город от первого лица, целиком нарисованный светящимся ASCII, по которому ходят все, кто открыл страницу. Район генерируется процедурно из зерна, и все позиции в нём принадлежат серверу.
* **Возможности:** Авторитетная симуляция на 20 Гц с клиентским предсказанием и сверкой, бинарный протокол WebSocket по десять байт на игрока, interest management, чат в районе и рядом. WebGL2-рейкастер выводит сетку символов одним инстансированным вызовом по атласу глифов, который сам несёт в себе неоновое свечение; есть запасной путь на Canvas2D и адаптивное качество. Бинарные тайлы по 256 м декодируются в Web Worker и кэшируются в MongoDB; вторая реализация порта мира импортирует размеченный GeoJSON из OpenStreetMap в тот же самый формат тайлов.

#### 11. [Mods](./minecraft_mods/) (Список модов Minecraft)

* **Описание:** Каталог модов Minecraft, чьи репозитории на GitHub заканчиваются на `mod`. Адрес — `/mods`.
* **Возможности:** Читает публичный аккаунт GitHub и показывает краткое описание, лицензию, ссылки на GitHub и Modrinth, jar мода из последнего релиза и jar зависимостей из того же релиза. `GET /mods/api/mods` возвращает эти карточки; `q`, `loader`, `minecraft` и `license` сужают список. `MODRINTH_TOKEN` помечает проекты, которые ещё на модерации.

## Установка и запуск

Репозиторий настроен для бесшовного запуска на Hugging Face Spaces (с использованием автоматической синхронизации через GitHub Actions), Vercel или локальных серверах.

### Системные требования
Для работы всех функций конвертации на хост-системе должны быть установлены:
* Python 3.10+
* MongoDB
* LibreOffice (Headless CLI)
* FFmpeg & FFprobe
* 7-Zip (`7z`)
* Зависимости библиотеки CairoSVG

### Установка

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/Nergan/projects.git
   cd projects
   ```

2. Соберите проекты, включённые выбранным профилем:
   ```bash
   chmod +x build.sh
   CUTAWAY_PROFILE=local ./build.sh
   ```

3. Настройте конфигурационные переменные в файле `.env` в корне проекта:
   ```env
   MONGODB_URI=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/
   ```

4. Запустите веб-сервер (локальный профиль по умолчанию использует `embedded`):
   ```bash
   chmod +x start.sh
   ./start.sh
   ```

Скрипт запустит Uvicorn на порту `7860`, принудительно инициализируя стандартный цикл событий `asyncio` для обхода распространенных проблем с таймаутом SSL-рукопожатия, возникающих на альтернативных loop-раннерах (таких как uvloop).
