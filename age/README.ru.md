# Age

[Read in English (README.md)](README.md)

Срез браузерной MMO. Два города, соединённых дорогой; дорога становится шире,
когда по ней идёт больше людей, и снова сужается, когда они уходят. Все, кто
открыл страницу, стоят в одном и том же мире, видят один и тот же рельеф и могут
в нём драться, строить, добывать и разговаривать.

Мир генерируется процедурно и **никогда не передаётся**. Сервер присылает
64-битное зерно, и браузер генерирует ровно те тайлы, что сгенерировал сервер —
тот же шум, те же хеши, те же биты. По сети идёт только то, что изменили игроки.

Арт тоже генерируется процедурно, и для него есть редактор по адресу
`/age/atelier`.

## Запуск

Проект зарегистрирован в `orchestrator.toml` и отдаётся хабом по адресу `/age`.
Ничего сверх обычной подготовки репозитория не требуется:

```bash
./build.sh          # ставит зависимости Python и собирает клиент
python main.py      # хаб, Age на /age
```

Отдельно, без хаба:

```bash
cd age && npm install && npm run build
cd .. && python -m age.main --port 8140
# затем откройте http://127.0.0.1:8140/age/
```

Для работы над клиентом `npm run dev` поднимает Vite с проксированием на сервер
на порту 8140: рельеф и сокет приходят с настоящего бэкенда, а интерфейс
перезагружается на лету.

## Управление

| Ввод | Действие |
| --- | --- |
| `W` `A` `S` `D` или стрелки | Ходьба |
| `Shift` | Бег |
| Мышь | Прицел — персонаж смотрит на курсор |
| `1` `2` `3` | Способности, по курсору |
| `F` | Добыть тайл под курсором |
| `B` | Построить деревянную стену на тайле под курсором |
| `Enter` | Чат; ещё раз `Enter` отправляет, `Escape` отменяет |
| `Tab` | Диагностика — задержка, тик, топология, число чанков |
| `+` `-` | Масштаб |

У чата две дистанции: **общий** слышат все, **локальный** — в радиусе 24 тайлов.

Добыча и строительство работают в пределах 4 тайлов. Срубите дерево — получите
древесину; расчищенный тайл потом сам поднимается обратно по лестнице
восстановления — земля, трава, саженец, куст, дерево — на одну ступень в минуту,
если его не рубят снова.

## Аккордеон

Это идея, вокруг которой построен проект, и она топологическая, а не
геометрическая. Мир не растягивается — он **приобретает и теряет полосы**.

Коридор между двумя городами длиной в восемь сегментов. На уровне 0 существует
только центральная полоса. Когда население переваливает за десять игроков, мир
расширяется до уровня 1 и появляются две боковые полосы — новый рельеф, новые
ресурсные узлы, новые NPC, втрое больше места. Когда население падает ниже пяти,
боковые полосы уходят, а тех, кто на них стоял, сначала выводят в хаб.

Два порога, а не один, потому что единственный порог на восьми игроках
переключал бы мир туда-обратно при каждом входе. И пятнадцать минут задержки
между изменениями, чтобы мир не «дребезжал».

Каждый чанк проходит через конечный автомат — `DORMANT → PREPARING → ACTIVE →
RETIRING → DORMANT` — и недопустимый переход выбрасывает ошибку, а не молча
исправляется. Чанк не может стать активным раньше, чем построен его рельеф, и не
может уйти, пока на нём стоит игрок.

Каждое изменение топологии увеличивает `topology_version`, и каждый кадр от
клиента его несёт. Ввод, адресованный миру, которого больше нет, отклоняется, а
не применяется к чужой полосе.

В демо уровень можно переключить вручную из панели диагностики: рабочая частота
изменений — пятнадцать минут, и сидеть столько никто не станет.

## Классы

Четырнадцать классов из четырёх половин. Каждая из половин — Воин, Лекарь, Маг,
Разбойник — даёт способность, а каждая пара даёт сверху свою уникальную. Так
4 + 4 + 6 = 14 наборов получаются из 14 определений способностей вместо
сорока с лишним, которые понадобились бы, если писать каждый набор руками.

| | Воин | Лекарь | Маг | Разбойник |
| --- | --- | --- | --- | --- |
| **Воин** | Воин → Военачальник | Паладин | Чароклинок | Наёмник |
| **Лекарь** | | Лекарь → Архижрец | Шаман | Проводник |
| **Маг** | | | Маг → Архимаг | Трюкач |
| **Разбойник** | | | | Разбойник → Владыка теней |

Удвоение половины даёт чистую специализацию; смешение — гибрида, который держит
обе половины плюс собственную уникальную способность.

## Как это работает

- **Сервер — источник истины.** Клиент присылает намерение: «вверх и влево, бегу,
  смотрю сюда, и мне кажется, я оказался вот в этой точке». Сервер сам
  интегрирует движение и возвращает игрока назад, если расхождение больше 1.5
  тайла. Соврать про позицию бесполезно, а соврать про время кадра не выйдет —
  оно ограничивается.
- **Локальное предсказание.** Клиент выполняет тот же код движения, поэтому
  ходьба мгновенная. На каждом снапшоте он откатывается к подтверждённой
  позиции, проигрывает неподтверждённый ввод заново и сглаживает остаточную
  ошибку за несколько кадров.
- **Детерминированный рельеф.** Четыре слоя: хребет дороги, три климатических
  поля, классифицирующихся в восемь биомов, пороговый разброс с проходом на
  связность, затем точки интереса. Каждое поле — функция глобальных координат,
  поэтому соседние чанки согласны насчёт общей границы, ничего друг у друга не
  спрашивая. Прохода по сшивке швов нет, потому что шва нет.
- **Разностные снапшоты.** Симуляция 30 Гц, снапшоты 15 Гц. На сущность: 4 байта
  идентификатора, 1 байт маски полей и только изменившиеся поля. Идущий игрок
  стоит 13 байт.
- **Свет по картам нормалей.** Каждый спрайт печётся с каналом высоты, который
  дифференцируется в карту нормалей. Рендерер рисует проход цвета и проход
  нормалей и сводит их вместе, поэтому фонарь в сумерках освещает бок стены, а не
  подкрашивает плоский прямоугольник.

Слои разложены гексагонально: `domain` держит правила, `application` их
организует, `infrastructure` говорит байтами и базами, `presentation` — HTTP и
WebSocket. Всё, что симуляции нужно извне, — это Protocol в `domain/ports.py`.

Здесь это важно по конкретной причине. Спецификация просит мировой сервер на Go;
монорепозиторий запускает Python-воркеры. Поэтому ядро здесь на Python и работает
на 30 Гц — и об этом сказано прямо. А поскольку ядро стоит за портами, а формат
провода не зависит ни от языка, ни от частоты тиков, ядро на Go или Rust можно
подставить позже, не тронув ни протокол, ни клиент, ни сами правила.

## Ателье

Делать сотни спрайтов через ИИ-сервис не воспроизводимо и не устойчиво, поэтому
арт **процедурный**: тайл — это рецепт из параметризованных операций, а не
уложенная руками сетка пикселей.

Это не компромисс ради демо. Поменяйте один базовый цвет — перекрасится целый
биом; поменяйте один параметр — вся брусчатка в мире станет грубее. Номер кадра —
такой же параметр, поэтому вода идёт рябью, а костёр мерцает, и никому не пришлось
рисовать по четыре версии всего.

Пиксель-артовый вид на самом деле берётся из дисциплины цвета. Затенение идёт по
сгенерированной лестнице из пяти оттенков со сдвигом тона — тени к синему, блики
к жёлтому — и с насыщенностью, которая в тенях **растёт**, потому что тёмный
участок в тени цветнее освещённого, а не бледнее. Если сделать наоборот,
сгенерированный арт выглядит как ползунок яркости.

Редактор в браузере по адресу **`/age/atelier`** перечисляет все рецепты, правит
их шаги и показывает рядом печать цвета и печать нормалей.

Для тех, кто предпочтёт рисовать в настоящем пиксель-артовом редакторе, есть
импорт уровней **LDtk** и листов **Aseprite**. Путь через LDtk вообще не требует
картинки тайлсета: рисуете классы рельефа как IntGrid, и числа *и есть*
идентификаторы тайлов, а сущность LDtk с именем `lantern` ставит рецепт
`lantern`.

Подробности — в [конвейере арта](docs/art-pipeline.md).

## Хранение

MongoDB, когда она доступна, и пропускается, когда нет. В ней лежат персонажи —
класс, внешность, уровень, инвентарь, последняя позиция — и наложение рельефа по
чанкам, сбрасываемое по интервалу, а не на каждую правку.

Потеря базы стоит сохранённых персонажей и правок игроков, и больше ничего: мир —
чистая функция от своего зерна. Запуск с `AGE_USE_MONGO=0` — законная
конфигурация, и посетитель разницы не заметит.

Cloudinary не используется. Игровой арт публичный и кешируется jsDelivr, как и
остальные ресурсы монорепозитория, — маскировать нечего; этот адаптер остаётся за
портом на будущее, для пользовательского контента.

## Настройки

Каждая переменная объявлена в списке разрешённых в `orchestrator.toml`. Значения
по умолчанию работают без всякой настройки.

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `AGE_WORLD_SEED` | `0x0A6E5EED` | Мир. По умолчанию фиксировано, чтобы двое, обсуждающих демо, обсуждали одно место |
| `AGE_CORRIDOR_SEGMENTS` | 8 | Длина коридора, ограничена 2–16 |
| `AGE_MAX_CLIENTS` | 50 | Размер комнаты |
| `AGE_USE_MONGO` | вкл | Персистентность |
| `AGE_TIER_COOLDOWN_SECONDS` | 900 | Понизьте, чтобы увидеть аккордеон за один сеанс |
| `AGE_ALLOW_DEV_CONTROLS` | вкл | Разрешает панели диагностики переключать уровень |
| `AGE_WORLD_ID` | `demo` | Пространство имён базы |

## Тесты

```bash
python -m pytest tests -k age    # 349 тестов сервера, ателье и паритета
cd age && npm test               # 126 тестов клиента
```

Несущие здесь — наборы на паритет. `age/tools/make_fixtures.py` замораживает
пакеты и целые сгенерированные чанки со стороны Python в
`frontend/src/__fixtures__/parity.json`; клиентский набор их декодирует и
генерирует заново и сравнивает тайл к тайлу, а проверка на pytest перегенерирует
файл, доказывая, что он актуален. Тест паритета константы читает
`frontend/src/domain/constants.ts` и сравнивает каждое общее число с
`domain/constants.py`.

Изменение константы или протокола только с одной стороны валит сборку, а не
рассинхронизирует игрока посреди сеанса. Это не теория: пока их писали, наборы
поймали два настоящих бага, оба — в поиске тайлов хаба, и оба делали город
появления непроходимым.

Посмотреть на всё без браузера:

```bash
python scripts/probe_age.py         # поднять мир без сети и снять здоровье цикла
python scripts/probe_atelier.py     # напечатать все рецепты в контрольные листы
python scripts/probe_character.py   # кадры персонажа в 10x
```

`probe_age.py` крутит настоящий цикл событий на настоящей частоте тиков, поэтому
его числа что-то значат — именно так нашлась генерация чанка за 712 мс и
подтвердилась замена на 24 мс. Пробы арта — то, чем осматривались пропсы, и они
поймали утёс, читавшийся как радиатор, и костёр, который вообще не анимировался.
