# ADR 0006: Гибридная постквантовая идентичность

## Статус
Принято (аудит 2026-08-25).

## Контекст
Оператор требует PQ и для пользователей, и для админа. Черновик
`research-en.md` предлагал Ed25519+ML-DSA-65, ML-KEM, ratchet, ZKP.
Нужно отделить hedge против квантового взлома **подписи** от защиты
бинарника (последнее PQ не даёт).

## Решение
- Подпись: Ed25519 **и** ML-DSA-65, оба обязательны.
- ML-KEM-768: для E2E тел админ-команд мимо TLS-терминатора Cloudflare.
  На клиентский `/auth` в v1 не вешаем.
- Не ZKP, не блокчейн, не обязательный TEE.
- `core/` потеряет «ноль зависимостей» для PQ и Reality: исключение из
  [ADR 0001](0001-zero-deps.md), отдельным модулем/require, с явным комментарием.
  Кандидат реализации: `github.com/cloudflare/circl` (проверить API ML-DSA
  на момент кода) либо другая FIPS 204 библиотека без GPL.

## Последствия
Worker WebCrypto сейчас стабильно даёт Ed25519; ML-DSA в workerd — за
флагом/PR. Verify PQ на origin до стабилизации. Золотые тесты совместимости
языков — обязательны, по образцу VLESS.
