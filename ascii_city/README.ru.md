# ASCII City

[Read in English (README.md)](README.md)

Многопользовательский город от первого лица, целиком нарисованный светящимся
ASCII. Все, кто открыл страницу, ходят по одной улице, видят один и тот же
силуэт кварталов, видят друг друга и могут разговаривать. Район генерируется
процедурно из зерна, и все позиции в нём принадлежат серверу.

## Запуск

Проект зарегистрирован в `orchestrator.toml` и отдаётся хабом по адресу
`/ascii-city`. Ничего сверх обычной подготовки репозитория не требуется:

```bash
./build.sh          # ставит зависимости Python и собирает клиент
python main.py      # хаб, ASCII City на /ascii-city
```

Отдельно, без хаба:

```bash
cd ascii_city && npm install && npm run build
cd .. && python -m ascii_city.main --port 8130
# затем откройте http://127.0.0.1:8130/ascii-city/
```

Для работы над клиентом `npm run dev` поднимает Vite с проксированием на сервер
на порту 8130: район и сокет приходят с настоящего бэкенда, а интерфейс
перезагружается на лету.

## Управление

| Действие | Что делает |
| --- | --- |
| `W` `A` `S` `D` или стрелки | Ходьба |
| `Shift` | Бег |
| Мышь | Обзор (щёлкните по окну, чтобы захватить курсор) |
| `Enter` | Открывает строку чата; повторный `Enter` отправляет, `Escape` отменяет |
| Левая половина сенсорного экрана | Виртуальный стик |
| Правая половина сенсорного экрана | Обзор |

У чата два радиуса: `district` слышат все, `nearby` — только те, кто ближе
тридцати метров. Кнопка слева от поля ввода переключает режим.

## Как это устроено

Единственный, кто знает, где кто находится, — сервер. Клиент присылает
*намерение*: «вперёд, чуть вправо, бегом, смотрю туда», — а сервер двадцать раз
в секунду отвечает позициями. Клиенту нет смысла врать о вводе: длину шага и
проверку столкновений считает сервер.

- **Мир.** Генератор по зерну рисует проспекты, улицы, кварталы и здания, после
  чего нарезает результат на тайлы по 256 м. В пределах версии мира тайлы
  неизменны, поэтому отдаются с длинным кэшем и сжимаются один раз на старте,
  а не на каждый запрос.
- **Транспорт.** Компактный бинарный протокол поверх WebSocket. Запись игрока в
  снапшоте занимает десять байт, так что полная комната на пятьдесят человек
  стоит около 10 МБ в минуту — на порядок меньше трафика, который выделяет
  проекту оркестратор.
- **Предсказание.** Клиент выполняет построчную копию серверного кода движения,
  поэтому ходьба ощущается мгновенной. Когда приходит снапшот, клиент
  откатывается к подтверждённой позиции, переигрывает неподтверждённый ввод и
  растворяет остаток расхождения за несколько кадров.
- **Рендер.** DDA-трассировка на каждый экранный столбец, продолженная за первую
  стену — чтобы башни за кварталом всё равно вырезали свой силуэт в небе.
  Результат — сетка символов, уходящая на GPU одним инстансированным вызовом
  отрисовки; в зелёном канале атласа глифов лежит размытая копия каждого
  символа, из неё и получается неоновое свечение.

Слои разделены по-гексагонально: `domain` знает правила, `application` их
оркеструет, `infrastructure` говорит на байтах и с базой, `presentation` — на
HTTP и WebSocket. Источник мира — это порт, и реализаций у него уже две:
процедурный генератор и импортёр OpenStreetMap, превращающий размеченный
GeoJSON в те же самые тайлы. Всё, что выше порта, различить их не может.

## Хранилище

MongoDB используется, когда доступна, и пропускается, когда нет. В ней лежит
кэш закодированных тайлов, дескриптор мира и короткая история чата с
TTL-индексом. Потеря базы стоит истории сообщений и нескольких секунд повторной
генерации на старте — и только: район остаётся чистой функцией от своего зерна.

Зависимости от CDN нет. Тайлы маленькие, неизменные и отдаются самим проектом —
так он остаётся самодостаточным.

## Тесты

```bash
python -m pytest tests -k ascii_city   # 249 тестов сервера, импорта и паритета
cd ascii_city && npm test              # 83 клиентских теста
```

Наборы связаны намеренно. `ascii_city/tools/make_fixtures.py` замораживает
данные, порождённые кодеками на Python; клиентский набор их декодирует, а
pytest-проверка перегенерирует фикстуры и убеждается, что они не устарели.
Тест паритета констант читает `frontend/src/domain/constants.ts` и сверяет
каждое общее число с `domain/constants.py`. Изменение протокола только с одной
стороны уронит сборку, а не рассинхронизирует игрока.

Посмотреть на город без браузера:

```bash
python -m ascii_city.main --port 8130
cd ascii_city && npx vite-node tools/preview-frame.ts -- --plain --yaw 120
```

`ascii_city/tools/preview.py` делает то же самое для генератора: печатает карту
района сверху и его статистику. А `ascii_city/tools/import_osm.py` печатает ту
же карту для района, импортированного из GeoJSON:

```bash
python -m ascii_city.tools.import_osm ascii_city/docs/samples/osm-district.geojson
```
