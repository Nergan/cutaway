# Evenfest — инструкции для AI-агентов

Evenfest — сайт сообщества на FastAPI и серверных шаблонах. Хаб отдаёт его на `/evenfest`. Тексты страниц лежат в MongoDB.

Сначала прочитай корневой `AGENTS.md`. Перед нетривиальной задачей найди подходящие скиллы в https://github.com/DietrichGebert/ponytail и примени их.

## Свои правила

- `GET /evenfest/api` отдаёт меню, `GET /evenfest/api/pages` — список страниц, `GET /evenfest/api/pages/{id}` — страницу. Неизвестная страница отвечает 404.
- Поле `content` шаблон вставляет в страницу. Не расширять его так, чтобы чужой документ получил общий origin соседних проектов.
- Подробности — в `README.md`.
