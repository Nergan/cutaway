# Formular — инструкции для AI-агентов

Formular — конвертер файлов внутри экосистемы cutaway: монорепозиторий, который целиком публикуется в один Hugging Face Docker Space вместе с десятком других проектов. Запланирована концептуальная переработка formular в any-to-any конвертер с общим рабочим пространством файлов, фоновыми задачами, API и AI-операциями.

**Статус на 2026-10-18: интерфейс и конвертер возвращены к снимку до переработки. Поверх этого снимка работают `speech.transcribe` и `speech.speak` (решения D17 и D18): озвучка следует языку текста, если для языка есть пермиссивный голос. Картинки не озвучиваются (D20). Сложная вёрстка PDF в markdown упрощается до текста, картинка содержания получает ссылку на Imgur (D22). Прямое медиа без флагов страница считает однопоточным ffmpeg.wasm, серверный ffmpeg остаётся (D23). Конфиги переводятся только друг в друга (D24). На Space один запрос до 128 МиБ, собранный файл до 3 ГиБ (D25). Результат по-прежнему до 128 МиБ. Решения D9–D16 остаются в силе для следующих этапов.**

Документация написана на русском языке, идентификаторы и пути — как в коде.

## Неснимаемые правила

- Не ломать хаб и соседние проекты. Маршруты `/formular` и `/formular/static`, лимиты и общий бюджет памяти в `orchestrator.toml`, тесты в `tests/` — это общие контракты.
- Перед любой правкой инфраструктуры и после неё прогонять:
  `python -m orchestrator.config --profile hf validate`, `python -m orchestrator.hosting_policy --profile hf`, `pytest -q tests`.
- Каталог `formular/` публикуется в HF Space. Ни в коде, ни в документации, ни в комментариях нельзя писать слова-триггеры сканеров: они перечислены в `_rules()` в `orchestrator/hosting_policy.py` (там они собираются из кусков, чтобы сам файл не срабатывал). Отдельно: нельзя упоминать название CDN-провайдера из правила `tunnel_worker` — автосканер HF ставил чужие Spaces на паузу за одно упоминание в документации. Headless-браузеры не добавлять.
- Не трогать настройки Space: пауза, смена железа, перенос, дублирование, смена SDK, factory rebuild, монтирование бакетов. Space работает на legacy-условиях, которые могут пропасть безвозвратно (`docs/02-constraints.md`, раздел 1).
- Пользовательские файлы никогда не отдавать inline с origin приложения: все проекты экосистемы делят один origin, и чужой HTML или SVG получит доступ к их данным (`docs/03-architecture.md`, раздел 10).
- AI выполняется только на своих ресурсах: CPU Space и браузер пользователя. Никакого входа через HF, Inference Providers и оплаты за счёт посетителя.
- Модели — только с пермиссивными лицензиями (список и исключения — в `docs/02-constraints.md`).
- Каждая AI-операция явно помечается в интерфейсе, в API и в метаданных результата.
- Решения, которые расходятся с документацией, сначала согласовать с владельцем и записать в таблицу решений в `docs/README.md`.

## Опыт

Если по ходу задачи стало ясно то, что в следующий раз сэкономит неверный ход, допиши это в этот `AGENTS.md`. Ход работы и разовую ошибку не копируй. Неверную старую строку поправь, а не оставляй вторую рядом.

Перед правкой публикации Space прочитай скилл [huggingface-spaces](https://github.com/huggingface/skills/blob/main/skills/huggingface-spaces/SKILL.md). Он не разрешает менять железо, паузу, SDK и не разрешает платный inference: AI остаётся на CPU Space и в браузере.

## Craft Anything

[Craft Anything](https://github.com/storytold/craft-anything) — ранняя альфа. Она смотрит, как устроена чужая программа, сайт или игра, и только по отдельной просьбе владельца собирает свою версию. Агенту достаточно `craft-anything-cli`; те же средства отдаёт `craft-anything-cli mcp`. Если команды нет, в середине задачи её не ставить и чужой файл вместо неё не вскрывать.

По умолчанию чистая комната: исходник, файлы и код страницы закрыты. Наружу попадает только видимое: снимок, текст, размеры, цвета, шрифты, открытые меню. Deep включается флагом `--deep` и читает код и файлы своими декодерами, а при установленной Ghidra ещё и ей. Это не песочница системы и не обход защиты, входа или античита. Цель берут только ту, которую владелец имеет право изучать. Логотипы, фотографии и чужой текст в репозиторий не копируют. Запись инструмента — свидетельство с уверенностью и оговорками, не замена нашему коду. Новая сборка по умолчанию уходит в `Documents/Craft Anything`. Править этот репозиторий ею можно только когда владелец просил сборку, с `--project-folder` на каталог репозитория и `--existing edit`. Установка зависимостей выполняет код пакетов; согласие «always allow» для `npm` не давать. Сверка сайта на трёх ширинах уже работает, сверка поведения программ и игр ещё неполная. Статус — `docs/STATUS.md` в том репозитории.

Конвертер — этот код и `docs/02-constraints.md`. Чужие загруженные файлы в Craft Anything не отправлять: Deep прочитал бы их байты. Чистая комната уместна, только если владелец просит сверить видимый экран образца, который можно смотреть, и затем править этот интерфейс. Headless-браузер не добавлять. Модели и озвучка остаются на своих правилах лицензий.
