# Текущее состояние formular

**Код на 2026-10-04:** приложение возвращено к снимку ниже. Пометки «Исправлено» в таблице проблем описывают отменённую переработку и в текущем коде отсутствуют. Поверх снимка добавлены распознавание речи и озвучка (решение D17 в `README.md`).

Снимок на 2026-10-03, версия фронтенда `APP_VERSION = '2.2.0'` (`static/js/app.js`). Текущая версия интерфейса — `2.3.0`.

## 1. Устройство

### Бэкенд (FastAPI, Python 3.11)
- `formular.py` — роутер проекта: `/` отдаёт `index.html`, `/api` подключает `api/endpoints.py`, все остальные пути редиректятся на корень. Хаб монтирует роутер на `/formular`.
- `main.py` — отдельный запуск вне экосистемы: `python main.py --web` (uvicorn) или десктопный режим через Eel.
- `api/endpoints.py`:
  - `POST /api/upload` — принимает файлы, кладёт каждый в `TEMP_DIR/<uuid>/input/`, определяет формат (`detect_file_format`), отдаёт допустимые цели (`get_allowed_targets`). Неизвестные форматы удаляются.
  - `POST /api/convert` — синхронная конвертация. Параметры: `file_id`, `to_format`, `audio_opts`, `video_opts` (JSON-строки), `custom_ffmpeg`, `merge_id`, `merge_loop`. Возвращает файл через `FileResponse`, каталог задачи удаляется сразу после отдачи. Таймаут 900 с, на HF фактически режется на 600 с прокси хаба.
  - Старые сессии удаляются при следующей загрузке, если старше `FORMULAR_SESSION_TTL_SECONDS` (на HF — 1800 с).
  - Лимиты: `FORMULAR_MAX_UPLOAD_BYTES` (на HF 32 МиБ), `FORMULAR_MAX_OUTPUT_BYTES` (128 МиБ), `FORMULAR_MAX_CONCURRENT_JOBS` (1), `RateLimiter` по IP: 10 загрузок и 10 конвертаций в минуту.
- `core/detector.py` — libmagic по первым 8 КБ, разбор ZIP-контейнеров (docx/xlsx/pptx/epub/odt), эвристики по расширению и содержимому для текстовых форматов, таблица `ALLOWED_CONVERSIONS` (что показывать пользователю).
- `core/converter.py`:
  - граф `DIRECT_EDGES` и поиск пути `find_shortest_path` — BFS без весов;
  - `convert_document` проходит путь по шагам, а опции (аудио, видео, merge) применяет только к последнему шагу;
  - `_direct_convert` диспетчеризует: форматы данных (json/yaml/toml/xml), LibreOffice, pandoc, PyMuPDF (pdf → html/txt), ffmpeg, Pillow, CairoSVG (с запретом внешних ссылок), 7-Zip (с проверкой путей, количества и размера распаковки), ddjvu;
  - `_run_ffmpeg` собирает команду: обрезка, масштаб, кроп, фильтры, темп, реверберация, бас, наложение аудио/видео (merge), пользовательские флаги через чёрный список.
- `core/html_pdf.py` — локальный HTML → PDF через печать headless Chromium с запретом внешних запросов. Удаляется из деплоя на HF; там работает фоллбэк через LibreOffice.

### Фронтенд (ванильный JS, без сборки)
Скрипты подключаются из `index.html`, зависимости — с CDN: SortableJS, JSZip, pdf.js, Bootstrap Icons, шрифт MedievalSharp, виджет доната.

- `app.js` — инициализация, горячие клавиши, вставка из буфера, клик по фону, предупреждение при закрытии вкладки.
- `uploader.js` — drag-and-drop (включая папки через `webkitGetAsEntry`), выбор файлов, вставка; по одному XHR на файл с прогрессом загрузки; кэш исходных файлов в `window.Formular.LocalFiles` для превью.
- `card.js` — карточка файла: превью (изображение, кадр видео через canvas, первая страница PDF через pdf.js), выбор формата, конвертация, скачивание результата (blob в памяти браузера), удаление; «прогресс» — асимптотический таймер, а не реальные данные.
- `dropdown.js` — выпадающий список формата с расширенными настройками:
  - сетка форматов-чипов;
  - таймлайн обрезки с ручками;
  - визуальный кроп с ручками по 8 направлениям;
  - аудиоэффекты (темп, реверберация, бас) с живым превью через WebAudio и пресетами (Slow+Reverb, Nightcore);
  - фильтры (grayscale/sepia/invert) с CSS-превью;
  - вкладка Merge (наложить аудио на видео или картинку и наоборот, с зацикливанием);
  - вкладка пользовательских флагов ffmpeg с клиентской валидацией.

  Иконка `bi-stars` возле формата означает «настройки изменены или формат совпадает с исходным».
- `bulk.js` — нижняя панель для выделенных карточек: пересечение допустимых форматов, массовая конвертация, ZIP через JSZip, удаление.
- `lasso.js` — прямоугольное выделение мышью и касанием; Shift/Ctrl добавляют к выделению; автоматический учёт прокрутки.
- `core.js` — тосты и переключение пустого состояния.
- CSS: тёмная тема с оранжевым акцентом `#ff6b35`, шрифт MedievalSharp, стеклянные панели с размытием, анимированные кнопки, оверлей «RELEASE TO FORGE».

### Поток данных сейчас
1. Пользователь загружает файл; сервер сохраняет его и определяет формат.
2. Пользователь выбирает формат и опции; браузер шлёт `POST /api/convert` и держит соединение до конца конвертации.
3. Результат приходит blob'ом, живёт только в памяти вкладки; на сервере каталог задачи удаляется сразу.
4. Исходники удаляются через 30 минут при следующей чьей-либо загрузке.

Отсюда: закрыл вкладку — результат потерян; вернуться к конвертации невозможно.

## 2. Что в UX обязательно сохранить

- Лассо мышью и касанием; добавление к выделению с Shift/Ctrl/Cmd.
- Ctrl/Cmd+A — выделить всё; Delete/Backspace — удалить выделенные; Esc — снять выделение и закрыть меню. Горячие клавиши не срабатывают, когда фокус в поле ввода.
- Вставка файлов из буфера обмена; перетаскивание файлов и целых папок в любое место страницы; полноэкранный оверлей при перетаскивании.
- Пока файлов нет, диалог выбора открывает только клик по пунктирному полю; клик по остальной странице его не открывает. Перетаскивание по-прежнему работает по всей странице. Плавающая кнопка «+» появляется, когда файл уже есть.
- Локальные превью без участия сервера: картинки, кадр видео, первая страница PDF.
- Живое превью аудиоэффектов через WebAudio и CSS-превью фильтров до конвертации.
- Визуальные инструменты: таймлайн обрезки, кроп с ручками, свой медиаплеер с перемоткой.
- Сортировка карточек перетаскиванием за ручку.
- Тосты внизу слева, панель массовых действий снизу, сдвиг FAB и тостов при её появлении.
- Предупреждение при закрытии вкладки, если есть несохранённые результаты.
- Визуальный стиль «кузницы»: тёмный фон, оранжевое свечение, MedievalSharp, тексты вроде «forge».

## 3. Известные проблемы и как их решать

| # | Проблема | Где | Решение |
|---|---|---|---|
| P1 | Вкладка Merge не появляется, если аудио загрузилось после видео: видимость вкладки пересчитывается только при создании карточки и при клике по формату | `dropdown.js`: `onFilesUpdated` вызывает `populateMergeDropdown`, но не `updateTabVisibility` | Исправлено: `onFilesUpdated` вызывает `updateTabVisibility` и не переключает уже открытую вкладку. Комбинации нескольких файлов как операции — позже |
| P2 | Кандидаты для Merge фильтруются по MIME из браузера (`File.type`), который для части форматов пустой | `populateMergeDropdown` | Исправлено: приоритет у формата сервера `serverFormat`, MIME остаётся запасным |
| P3 | Операции с несколькими входами спрятаны внутри выпадающего списка одной карточки; массовая панель показывает только пересечение форматов и упирается в «Incompatible formats» | `dropdown.js`, `bulk.js` | Реестр операций с ролями входов, панель действий по выделению, пометка «N пропущено» |
| P4 | Синхронная конвертация: соединение держится до 10 минут, результат только в памяти вкладки, сервер сразу удаляет выход; «прогресс» поддельный | `endpoints.py: convert_file`, `card.js: doConvert` | Фоновые задачи с очередью, реальным прогрессом и хранением результата до истечения срока (`03-architecture.md`) |
| P5 | На HF `max_concurrency = 1`: пока отдаётся одна конвертация, остальные запросы к `/formular` (даже страница и CSS) через 5 с получают 503 | `orchestrator/governor.py: request_slot`, `orchestrator.toml` | Частично: на профиле hf `max_concurrency = 6` и `heavy_jobs = 1`. Сама конвертация всё ещё держит соединение |
| P6 | Вероятное убийство worker за CPU: кодирование видео занимает ~2 ядра (VP9 с `-threads 4`), а супервизор останавливает worker после 30 с выше 180%. Требует проверки на Space | `converter.py: _run_ffmpeg`, `orchestrator/supervisor.py` | Частично: встроенный ffmpeg ограничен двумя потоками, на posix тяжёлый процесс получает низкий приоритет. Политика CPU супервизора не менялась и на Space не проверялась |
| P7 | Утечка обработчиков: `updateBulkPanel` при каждом изменении выделения заново вызывает `initCustomSelect(bulkTarget)`, а тот каждый раз добавляет обработчики `mousemove`/`mouseup` на `document` и подписку на `formular:filesUpdated`. Каждая карточка тоже добавляет свои обработчики на `document` и никогда их не снимает | `bulk.js`, `dropdown.js` | Исправлено: повторный вызов снимает прежние обработчики через `destroy` |
| P8 | Путь ищется BFS без весов (README обещает Дейкстру); две таблицы `ALLOWED_CONVERSIONS` и `DIRECT_EDGES` поддерживаются вручную и расходятся; опции применяются только к последнему шагу | `detector.py`, `converter.py` | Частично: оба списка в `registry.py`, путь взвешенный. Опции по-прежнему применяются к последнему шагу |
| P9 | Пользовательские флаги ffmpeg проверяются чёрным списком. Фильтры вроде `drawtext=textfile=...` или `subtitles=...` читают файлы по относительному пути без `/`, что проверка пропускает. Сейчас риск низкий (секреты не лежат в файлах рабочего каталога), но подход хрупкий | `converter.py: _run_ffmpeg`, `dropdown.js: isValidFFmpegFlags` | Исправлено: белый список флагов и фильтров, файловые фильтры запрещены |
| P10 | Ошибки отдаются как `detail=str(e)`, а разбор опций глушится через `except: pass` | `endpoints.py`, `converter.py` | Исправлено: ошибки параметров — 422, прочие сбои конвертации без текста исключения |
| P11 | Загрузка — один запрос на файл с лимитом 32 МиБ, без докачки | `uploader.js`, `endpoints.py` | Обработка больших файлов в браузере; для сервера — чанковая загрузка (`05-api.md`) |
