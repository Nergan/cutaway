# UX-спецификация

Новый интерфейс должен быть не менее удобным, чем текущий. Всё из `01-current-state.md`, раздел 2, сохраняется. Модель данных и планировщик — в `03-architecture.md`.

## 1. Принципы

1. **Сначала объект, потом действие.** Пользователь выбирает файлы, интерфейс предлагает применимые действия. Обратный путь — через палитру команд: сначала действие, потом недостающие файлы.
2. **Недоступное не прячется молча.** Неприменимые действия показываются отключёнными с причиной («нужен ещё аудиофайл», «формат не поддерживается в браузере, выполнится на сервере»).
3. **Каждый результат — новая карточка** с указанием, из чего и как она получена.
4. **Прогрессивное раскрытие:** пресет → основные параметры → «Дополнительно» → экспертный режим.
5. **Всё доступно тремя способами:** мышью, клавиатурой и касанием.
6. **Честность:** путь, место выполнения, время, потери качества и AI видны до запуска.

## 2. Визуальный стиль

Сохранить «кузницу»:
- чёрный фон с тёплыми радиальными градиентами, оранжевый акцент `#ff6b35` и свечение;
- шрифт MedievalSharp, стеклянные панели с размытием, пружинящие анимации кнопок;
- оверлей «RELEASE TO FORGE» при перетаскивании, тосты внизу слева, плавающая кнопка «+» внизу справа.

Новые элементы (панель действий, палитра, панель задач) — в том же языке, что текущие выпадающие списки и панель массовых действий.

## 3. Раскладка

- **Пустое состояние** — как сейчас (клик или перетаскивание в любое место), плюс подсказки: «Ctrl+V — вставить», «Ctrl+K — команды», «можно бросить папку».
- **Рабочее пространство** — сетка или список карточек с переключателем вида. Сортировка перетаскиванием за ручку, как сейчас.
- **Панель действий** — развитие текущей нижней панели массовых действий. Появляется при выделении; на широком экране может стать боковой.
- **Панель задач** — выдвижная: очередь, прогресс, история.
- **Шапка рабочего пространства** появляется после первой серверной загрузки: ссылка с кнопкой «скопировать», QR-код, таймер до удаления, «удалить всё сейчас», меню истории рабочих пространств.

## 4. Карточка ассета

- Превью — как сейчас: изображение, кадр видео, первая страница PDF. Для аудио — волна; для 3D — интерактивное превью в three.js по клику; для архива — число файлов и раскрытие содержимого.
- Имя, размер, определённый формат. Если формат определён неуверенно — значок с выбором альтернативы.
- Значок происхождения: «из *имя* → *операция*». Клик подсвечивает родителя.
- Состояния: загружается (с реальным прогрессом), готов, в очереди, обрабатывается (реальный процент и этап), ошибка (с причиной и «повторить»), истёк.
- Значок AI, если ассет получен с участием AI (раздел 9).
- Быстрые действия: скачать, «Конвертировать в…», меню «ещё».
- Коллекции (архив, многостраничный PDF, кадры) раскрываются, элементы можно выделять отдельно.

## 5. Выделение

- Клик — выделить одну карточку; Ctrl/Cmd+клик — переключить; Shift+клик — диапазон от опорной карточки (как в toadcode, `toadcode/scripts/vfs.js`).
- Лассо мышью и касанием — как сейчас (`static/js/lasso.js`). Shift, Ctrl или Cmd добавляют к выделению.
- Стрелки двигают фокус, Shift+стрелки расширяют выделение, Ctrl/Cmd+A выделяет всё, Esc снимает выделение.
- На телефоне долгое нажатие включает режим выделения, дальше касания переключают карточки.
- Перетаскивание за ручку меняет порядок, перетаскивание за тело карточки — комбинирование (раздел 7). На касании — долгое нажатие на теле.

## 6. Панель действий

Строится по выделению через планировщик (`03-architecture.md`, раздел 3).

### «Конвертировать в…»
- Сетка форматов-чипов, как сейчас, с поиском и группами по видам. Недавние форматы — первыми.
- При наведении или выборе — строка пути, например `PDF → TXT → MP3`, со значками:
  - где выполняется каждый шаг: браузер или сервер;
  - потери: без потерь, с потерями, теряется структура;
  - AI, если он есть в пути;
  - оценка времени.
- Если путей несколько — переключатель «оптимально / быстрее / качественнее».

### «Действия»
- Группы: изменить, извлечь, собрать, создать, проанализировать, запрос, AI.
- Параметры открываются в той же панели. Редакторы параметров — текущие инструменты: таймлайн обрезки, визуальный кроп, слайдеры аудиоэффектов с живым превью через WebAudio, CSS-превью фильтров.
- Экспертный режим для ffmpeg — только поля из белого списка флагов.

### «Комбинации» (при нескольких выделенных)
- Операции, роли которых можно заполнить выделенными файлами. Если роли неочевидны — короткий выбор «что из этого видео, а что аудио».
- Пакетные операции для разнородного выделения: действие применяется к подходящим, остальные помечаются «N пропущено» с объяснением при наведении. Вместо тупика «Incompatible formats».

### Запуск
- Кнопка показывает, что произойдёт: «Конвертировать 3 файла в WEBM (в браузере)».
- Enter запускает действие по умолчанию, Ctrl/Cmd+Enter — все подготовленные действия.

## 7. Комбинирование перетаскиванием

- Когда карточку тянут за тело, совместимые карточки подсвечиваются, несовместимые приглушаются.
- При отпускании на совместимую карточку — всплывающее меню операций для этой пары:
  - аудио на видео — «Заменить дорожку / Смешать / Добавить вторую дорожку»;
  - картинка на аудио — «Сделать видео (картинка + звук)», «Видео с волной»;
  - субтитры на видео — «Вшить в картинку / Встроить дорожкой»;
  - картинка на видео или PDF — «Водяной знак / Картинка в картинке»;
  - CSV/JSON/XLSX на шаблон DOCX/ODT/PPTX — «Заполнить шаблон для каждой строки»;
  - JSON на PDF-форму — «Заполнить форму»;
  - текст песни на аудио — «Синхронизировать текст (LRC)» (AI);
  - файл на архив — «Добавить в архив».
- Отпускание на пустое место — отмена.
- Клавиатурная альтернатива: выделить оба файла и нажать Ctrl/Cmd+K — палитра покажет комбинации.

## 8. Палитра команд

- Открывается по Ctrl/Cmd+K или «/». Нечёткий поиск по действиям, форматам, файлам, рецептам и настройкам, на русском и английском: «в pdf», «транскрибировать», «убрать фон», «сжать до 25 мб».
- Учитывает выделение: сначала действия, применимые к выделенному.
- Сценарий «сначала действие»: выбрал «Заменить аудиодорожку» → палитра просит выбрать видео, потом аудио (список фильтруется по ролям) → параметры → запуск.
- История последних команд.

## 9. Пометка AI

- Единый значок «AI»: свой цвет (например, фиолетовый, чтобы не смешиваться с оранжевым акцентом) и своя иконка. **Не `bi-stars`** — в текущем интерфейсе она означает «настройки изменены».
- Где показывается: на AI-операциях в панели и палитре, в строке пути, на задаче, на ассете-результате, в списке шагов рецепта.
- Подсказка по значку: модель со ссылкой на HF, лицензия (с атрибуцией для CC-BY), где выполняется, оценка времени, короткое предупреждение о возможных ошибках.
- При первом AI-запуске — одноразовое пояснение (запоминается в `localStorage`): что такое AI-операции, где они выполняются, что результат помечается.
- Выбор модели: «Авто (рекомендуется)» и поле для своей модели с автодополнением по HF и результатом проверки. Если модель не проходит фильтры (лицензия, размер, формат весов, пользовательский код) — объяснить причину.
- Для браузерных AI-шагов — размер скачивания модели и предупреждение, если устройство слабое (мало памяти, нет WebGPU).

## 10. Задачи, ссылка и уход со страницы

- Панель задач показывает: позицию в очереди, этап, реальный процент, ETA, короткий лог, «отменить», «повторить».
- Явное различие исполнителей:
  - браузерный шаг — «Выполняется в вашем браузере. Не закрывайте вкладку». Предупреждение при закрытии вкладки включается только пока идут браузерные шаги или есть несохранённые браузерные результаты;
  - серверная задача — «Можно закрыть вкладку и вернуться по ссылке до *время*».
- Когда задача завершилась, а вкладка скрыта: уведомление браузера (разрешение спрашивается при первой долгой задаче, не при загрузке страницы) и счётчик в заголовке вкладки.
- Ссылка: кнопка «скопировать», QR-код (генерируется в браузере), предупреждение «без этой ссылки файлы не восстановить», таймер до удаления, «удалить всё сейчас».
- Если сервер перезапускался: задачи показывают «восстановлено» или «файл потерян при перезапуске сервера — загрузите снова».
- Без фрагмента `#k=` в ссылке: «Ссылка неполная — зашифрованные файлы недоступны».

### Сценарии для ручной проверки
1. Загрузить видео, потом аудио; выделить оба; заменить дорожку через панель, через перетаскивание и через палитру.
2. Выделить лассо 20 файлов разных типов; «Конвертировать в PDF»; убедиться, что неподходящие помечены «пропущено».
3. Запустить долгую серверную задачу, закрыть вкладку, открыть ссылку через 10 минут — результат на месте.
4. Цепочка «PDF → озвучка» показывает путь с AI-шагом и меткой; результат помечен AI в UI и метаданных.
5. Всё из пунктов 1–4 — только с клавиатуры и только касанием на телефоне.

## 11. Рецепты

- Цепочка записывается автоматически, когда пользователь обрабатывает результат дальше. Явный конструктор — список шагов с параметрами.
- Сохранить рецепт (в `localStorage`; в рабочем пространстве — на время его жизни), применить к выделенному, экспортировать JSON (тот же формат, что в API), импортировать JSON.
- AI-шаги в рецепте помечены.

## 12. Горячие клавиши

На macOS вместо Ctrl используется Cmd (определять платформу, как в `toadcode/scripts/vfs.js`). Клавиши не срабатывают, когда фокус в поле ввода.

| Клавиши | Действие | Статус |
|---|---|---|
| Ctrl+A | Выделить всё | есть |
| Delete / Backspace | Удалить выделенные (с возможностью отмены) | есть, добавить отмену |
| Esc | Снять выделение, закрыть меню и панели | есть |
| Ctrl+V | Вставить файлы; вставленный текст становится `.txt`-файлом | есть для файлов, текст — новое |
| Ctrl+Z / Ctrl+Y (Ctrl+Shift+Z) | Отменить / повторить удаление, переименование, перестановку | новое |
| Клик / Ctrl+клик / Shift+клик | Выбрать / переключить / диапазон | Shift и Ctrl — новое |
| Стрелки / Shift+стрелки | Фокус / расширение выделения | новое |
| Пробел | Быстрый просмотр выделенного файла | новое |
| Enter | Действие по умолчанию для выделения | новое |
| Ctrl+Enter | Запустить подготовленные действия для всех выделенных | новое |
| Ctrl+K или `/` | Палитра команд | новое |
| Ctrl+S | Скачать выделенные (несколько — ZIP-архивом) | новое |
| F2 | Переименовать | новое |
| Ctrl+J | Панель задач | новое |
| `?` | Шпаргалка по клавишам | новое |

## 13. Мобильные устройства и доступность

- Крупные зоны касания; панель действий как нижняя шторка; никаких действий, доступных только по наведению.
- Кастомные списки и панели — с ролями ARIA (`listbox`, `option`, `grid`, `dialog`), фокусом и управлением с клавиатуры. Сейчас они недоступны с клавиатуры.
- Видимые рамки фокуса, достаточный контраст, учёт `prefers-reduced-motion`.

## 14. Ошибки и производительность

- Сообщения человеческим языком: что случилось, на каком шаге пути, что сделать. Без стектрейсов и путей сервера.
- Виртуализация списка при большом числе карточек.
- Один набор делегированных обработчиков на страницу вместо обработчиков на каждую карточку; один общий `AudioContext` (`01-current-state.md`, P7, P14).
- Интерфейс сейчас на английском; лендинг экосистемы переводится. Предусмотреть русский и английский тексты через словарь.
