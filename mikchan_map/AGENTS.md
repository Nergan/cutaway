# Карта MikChan — инструкции для AI-агентов

Страница `/mikchan-map`. Хаб отдаёт её как проект `mikchan_map`. Сначала прочитай корневой `AGENTS.md`.

Карта, которую игрок открывает клавишей M, лежит в кэше Xaero's World Map, не в архиве `region.xaero`. Файл `.xwmc` — zip с `cache.xaero`. `cache_1` — листья, 512 блоков на файл, один пиксель на блок. `cache/1`, `cache/2`, `cache/3` — те же 512 пикселей, но на 1024, 2048 и 4096 блоков. Пиксель с нулевой альфой пустой: у веток это красная заглушка, её нельзя рисовать. Папка `*_backup_*` и `*.xwmc.outdated` не источник.

На Space эти файлы не класть. `python -m mikchan_map.convert` читает папку Xaero, пишет lossless WebP и заливает уже готовые картинки на тот же хост картинок, что soon и netlazy. Повторный запуск с тем же `--out` заново заливает тайл, только если исходный `.xwmc` новее уже собранной картинки. Файл `uploaded.txt` без отметки времени считается уже залитым, пока картинка не старше кэша. Оригиналы публичные: обложка с шифртекстом здесь удвоила бы чужую квоту, а ключ всё равно оказался бы в странице. Секрет загрузки в воркер не прокидывать. Имя облака берётся из окружения.

Метки читаются из `minimap/.../mw$default_1.txt`. Предложения добавить, переименовать или удалить метку пишутся в базу `mikchan_map`, коллекция `suggestions`. Каталог тайлов — коллекция `catalog`. Базу `mikchan` и коллекции дашборда не трогать.

## Опыт

Общий клиент Mongo — motor, его курсор нельзя обходить обычным циклом: каталог и предложения читаются через `await`.
