# Minecraft mods — инструкции для AI-агентов

Страница списка модов. Хаб отдаёт её на `/mods`. Карточки собираются из репозиториев GitHub, чьи имена кончаются на `mod`, и из страниц Modrinth.

Сначала прочитай корневой `AGENTS.md`. Перед нетривиальной задачей найди подходящие скиллы в https://github.com/DietrichGebert/ponytail и примени их.

## Свои правила

- Состав списка задают имена репозиториев и теги релизов `minecraft-<версия>-<загрузчик>`. Не вписывать моды вручную в страницу.
- `MODRINTH_TOKEN` и `GITHUB_TOKEN` необязательны. Без них страница остаётся рабочей: неготовый проект Modrinth показывается как ещё не публичный, а лимит API GitHub просто ниже.
- `GET /mods/api/mods` — контракт карточек. Подробности — в `README.md`.
