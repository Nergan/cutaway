# Soon

Одна общая онлайн-доска без аккаунтов. Все видят одно пространство. Штрихи хранятся в MongoDB, картинки — в GridFS.

## Возможности

- Выбор, рука, карандаш, кистевой ластик, лассо и вставка картинок (размер и поворот через выделение)
- Чат на T (как в Minecraft), история 300 сообщений в памяти комнаты
- Спектр цвета с прозрачностью (RGBA), русский и английский интерфейс
- Горячие клавиши по физическим клавишам, на любой раскладке
- Ctrl+C / Ctrl+V / Ctrl+Z / Ctrl+Y, вставка картинок из буфера и drag-and-drop
- Живые курсоры, список людей, уникальный ник, переход к человеку
- Метки по краям экрана, если чужой курсор вне кадра
- Сворачиваемая боковая панель поверх холста, адаптация под телефон

## Запуск

Из корня монорепозитория доска доступна по адресу `/soon`. Локально:

```bash
pip install -r requirements.txt
python main.py --web
```

Откройте [http://localhost:8000/soon](http://localhost:8000/soon). Нужна переменная `MONGODB_URI`, иначе доска живёт только в памяти процесса (картинки при этом не сохраняются).
