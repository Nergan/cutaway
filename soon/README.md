# Soon

Одна общая онлайн-доска без аккаунтов. Все видят одно пространство. Штрихи хранятся в MongoDB, картинки — в Cloudinary (дедуп по SHA-256; с доски и с CDN удаляются вместе).

## Возможности

- Выбор, карандаш, кистевой ластик и картинки (размер и поворот через выделение; Ctrl сохраняет пропорции)
- Рамка выделения как в проводнике (перетаскивание пустого места), холст — СКМ или пробел
- Чат на T (как в Minecraft), история 300 сообщений в памяти комнаты
- Спектр цвета с непрозрачностью (RGBA), русский и английский интерфейс
- Горячие клавиши по физическим клавишам, на любой раскладке
- Ctrl+C / Ctrl+V / Ctrl+Z / Ctrl+Y, вставка картинок из буфера и drag-and-drop
- Живые курсоры, список людей, уникальный ник, переход к человеку
- Метки по краям экрана, если чужой курсор вне кадра
- Сворачиваемая боковая панель поверх холста, адаптация под телефон

## Запуск

Из корня монорепозитория доска доступна по адресу `/soon`. Локально:

```bash
pip install -r requirements.txt
python main.py --web
```

Откройте [http://localhost:8000/soon](http://localhost:8000/soon). Нужны `MONGODB_URI` и переменные Cloudinary (`CLOUDINARY_URL` или `CLOUDINARY_CLOUD_NAME` / `CLOUDINARY_API_KEY` / `CLOUDINARY_API_SECRET`), иначе картинки не сохраняются.
