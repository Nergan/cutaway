# Toadcode — инструкции для AI-агентов

Toadcode — браузерное рабочее место для небольшого текстового проекта. Хаб отдаёт его на `/toadcode`. Дерево файлов публикуется в MongoDB, страница `/toadcode/{id}` только для чтения.

Сначала прочитай корневой `AGENTS.md`. Перед нетривиальной задачей найди подходящие скиллы в https://github.com/DietrichGebert/ponytail и примени их.

## Свои правила

- Лимиты одного рабочего места: 2000 файлов, 512 КиБ в одном файле, 8 МиБ текста всего. Путь с `..` или пустым сегментом отклоняется.
- Импорт архива репозитория не должен превращать проект в загрузчик произвольных адресов. Разрешённые хосты — в `orchestrator.toml`.
- Маршрут и контракт `GET /toadcode/api` не ломать. Подробности — в `README.md`.
