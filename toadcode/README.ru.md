# Toadcode

[Read in English (README.md)](README.md)

Toadcode — браузерное рабочее пространство для небольшого текстового проекта. Страница `/toadcode` — это дерево файлов и редактор: можно добавлять файлы и папки, перетащить zip или импортировать архив публичного репозитория GitHub или Hugging Face. Публикация сохраняет дерево в MongoDB и открывает страницу только для чтения по адресу `/toadcode/{id}`.

То же сохранённое пространство можно создавать, читать и править по HTTP.

## API

Маршруты отдаёт хаб с префиксом `/toadcode`. `GET /toadcode/api` возвращает карту маршрутов.

Файл — это JSON-объект:

```json
{"path": "src/hello.txt", "content": "hi", "is_dir": false}
```

У папки `"is_dir": true`, пустой `content` и путь с `/` на конце. Запрос с `"path": "box"` и `"is_dir": true` сохраняется как `box/`. В путях прямые слэши. Путь с `..` или пустым сегментом отклоняется.

Пределы одного пространства: 2000 файлов, 512 КиБ символов в одном файле и 8 МиБ текста всего. Запись ограничена 20 запросами в минуту с одного клиента.

### Создание

`POST /toadcode/api/repos`

```json
{"files": [{"path": "hello.txt", "content": "hi", "is_dir": false}]}
```

Ответ `201`:

```json
{"id": "...", "token": "...", "editable": true, "files": [...]}
```

Токен возвращается только из этого вызова. Дальнейшие записи передают его как `Authorization: Bearer <token>` или заголовком `X-Toadcode-Token`.

Пустой массив `files` создаёт пустое пространство, которое можно наполнить записью отдельных файлов.

### Чтение

`GET /toadcode/api/repos/{id}` возвращает `id`, `editable` и `files`. Токен в этот ответ не входит.

`GET /toadcode/api/repos/{id}/files/{path}` возвращает один файл. В пути могут быть слэши, например `box/b.txt`.

### Замена, запись и удаление

Этим вызовам нужен токен.

`PUT /toadcode/api/repos/{id}` с телом `{"files": [...]}` заменяет всё дерево.

`PUT /toadcode/api/repos/{id}/files/{path}` с телом `{"content": "updated", "is_dir": false}` создаёт или перезаписывает этот путь. Для папки отправьте `{"content": "", "is_dir": true}`.

`DELETE /toadcode/api/repos/{id}/files/{path}` удаляет файл. Удаление папки удаляет её и все пути внутри.

`DELETE /toadcode/api/repos/{id}` возвращает `204` и удаляет пространство.

Нет токена или он неверный — `401`. Неизвестный id или путь — `404`. Путь или тело, которое нарушает правила выше, — `400`. Тело больше предела размера — `413`.

### Публикация со страницы

Кнопка публикации вызывает `POST /toadcode/api/save`:

```json
{"id": "client-chosen-id", "files": [...]}
```

Ответ: `{"status": "success", "id": "..."}`. Одинаковое дерево хранится один раз, и повторное такое же сохранение возвращает уже существующий id. Страница только для чтения: `/toadcode/{id}`.

Это пространство читается через `GET /toadcode/api/repos/{id}`. Токена правки у него нет, поэтому запись отвечает `403`.

### Пример

```bash
curl -s -X POST "$ORIGIN/toadcode/api/repos" \
  -H "Content-Type: application/json" \
  -d '{"files":[{"path":"hello.txt","content":"hi","is_dir":false}]}'
```

`id` из ответа подставляется в `GET $ORIGIN/toadcode/api/repos/{id}`. `token` передаётся в `PUT` и `DELETE`.

Страница также вызывает `GET /toadcode/api/backgrounds` за списком видео и `GET /toadcode/api/proxy-zip?url=` чтобы скачать разрешённый публичный архив.
